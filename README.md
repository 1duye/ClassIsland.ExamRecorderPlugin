# ExamAware2联系人

在 ClassIsland 里把科目标成「考试科目」，当天的课表就会自动变成一份 ExamAware 的考试档案，推给「自动放映」插件去开播。

---

## 为什么有这个东西

ClassIsland 知道今天第几节上什么课，ExamAware 知道怎么把考试档案放出来，但两边不通气：老师得自己看课表、自己算时间、自己去 ExamAware 打开档案。

这个插件做两件事：**记录**（把当天考试科目的起止时间整理成 `.ea2`）和**通知**（把档案路径推给 ExamAware）。放映本身交给 ExamAware 端的 **「自动放映」**（`examaware-auto-player`）插件。

## 它能做什么

- **按科目标记，不用改科目名**。以前要往科目名后面加 `_考试`，现在在科目编辑页打开「考试科目」开关就行，以后新建的科目同样生效。
- **自动生成当天档案**。把课表里考试科目的时间整理成 `.ea2`，启动时顺手清掉过期的档案。
- **生成完就推**。立刻 POST 给「自动放映」，让它排程。
- **下课重推一次**。课表临时调整过，也不会拿着旧计划不放。
- **连堂自动合并**。同一个科目连着排两节，合成一场考试，不会在课间被当成"考完了"。
- **端口自动发现**。ExamAware 换端口了也不用回来改设置。

## 安装

1. 下载 `.cipx`，在 ClassIsland **设置 → 插件 → 从本地安装** 里选它。
2. ClassIsland 版本不低于 **2.0**。
3. ExamAware 端装上 **「自动放映」**，并打开它的 HTTP API。

## 用起来

### 1. 标记考试科目

**档案编辑 → 科目**，选中要考的科目，在右边 **「更多选项」** 里打开 **「考试科目」**。

- 每个科目各有一份开关，之后新建的科目也能用。
- 这里还能给这个科目单独设提醒时间，覆盖全局默认值。
- 标完记得在档案编辑器里**保存**。

### 2. 排进课表

把这些科目排进当天课表，剩下的交给插件。

### 3. 确认连接

**设置 → ExamAware2联系人**，点「检测连接」，显示「已连接」就通了。设置页里还有一行「当前推送地址」，能直接看到这次会往哪个端口推、端口是自动发现的还是手填的。

## 设置

| 设置项 | 默认 | 说明 |
| --- | --- | --- |
| 默认提醒时间 | 15 分钟 | 写进档案的提前提醒分钟数，单个科目可覆盖。 |
| 合并连堂考试 | 开 | 同一考试科目的相邻两节课合并成一场（见下）。 |
| 兼容旧命名 | 关 | 额外把科目名以 `_考试` 结尾的科目也当考试科目。 |
| 自动发现端口 | 开 | 读 ExamAware 上报的端口，EA 换端口也能跟上（推荐）。 |
| EA 端 HTTP API 地址 | `127.0.0.1` | 同一台电脑就保持默认。 |
| 端口 | `31235` | 只在关掉「自动发现端口」时才用得上。 |
| 放映时隐藏主界面 | 关 | 考试开始（进入放映）时自动隐藏 ClassIsland 主界面。 |
| 结束后恢复主界面 | 关 | 考完自动把主界面显示回来。 |

设置页还会显示连接状态、最近一次记录与推送结果、已标记的考试科目列表，以及「立即重新生成」按钮 —— 标完科目不用等下课，点一下就能立刻重算并推送。

## 连堂合并是怎么判的

四个条件同时满足才会合并：

1. 两节课在课表上**紧挨着**（中间没有别的课）；
2. **同一个科目**（按科目 ID 比，不是按名字）；
3. 两节**都是考试科目**；
4. 设置里「合并连堂考试」**开着**。

另外两节课的间隔要 **≤ 15 分钟**才算连堂。正常课间（5–10 分钟）会并进来；像上午最后一节接下午第一节这种跨午休的，会当成两场，不会误并。

合并后：开始时间取第一节，结束时间取第二节的结束，名字和提醒时间沿用第一场。三节连堂也会一路并成一场。

## 关于端口（重要）

ExamAware 的 HTTP API 端口会被它自己顺延（原因见「自动放映」的 README），所以这个插件**不再死记一个端口**：

- 每次推送前读 `%APPDATA%\@dsz-examaware\desktop\auto-player-endpoint.json`（ExamAware 端每 5 秒刷新一次）；
- 文件在、且是 10 分钟内更新的，就用里面的端口；
- 读不到或者太旧，才退回设置里的「端口」。

日志里会写清楚这次用的哪个：

```
push -> http://127.0.0.1:31249/api/v1/examaware-auto-player/signal mode=active-or-future source=自动发现 · 端口 31249
push OK: ...\data\EA2\考试记录_20261017.ea2
```

如果你在旧版本里手填过端口，升级后建议把「自动发现端口」保持开启，别再手工对齐。

## 已知问题

- **只在本机通信**。走 127.0.0.1，不支持跨电脑。
- **档案按「当天」生成**，不能提前给未来某天排程。
- **同名科目在档案里会显示成同一个考试名**，重名问题得靠课表本身避免。
- **课表当天没有考试科目就不会生成档案**，也不推送（设置页的科目列表为空就是这种情况）。
- **旧版的 `_考试` 后缀默认不再生效**，老配置要延续就打开「兼容旧命名」。
- **主界面联动依赖主窗口存在**，主窗口没就绪时会跳过隐藏 / 恢复（日志里有记录）。

## 常见问题

**设置页显示「未连接」？**
看 ExamAware 有没有开 HTTP API、有没有装「自动放映」；再看「当前推送地址」里的端口和实际端口是否一致。开了自动发现的话，多半是 EA 端插件没在运行。

**科目已经标了，为什么没反应？**
确认三件事：开关开了、这个科目当天确实排进了课表、档案编辑器里点了保存。然后点一下「立即重新生成」。

**连堂没合并？**
看四个条件：中间有没有夹别的课、是不是同一个科目、两节是否都是考试科目、开关是否打开。还有两节之间别超过 15 分钟。

**考试档案在哪？**
`data\EA2\考试记录_yyyyMMdd.ea2`，启动时会清掉非当天的。
